# The Inner Circle

# The 1% Club — Phase 0: Design System Frontend-only prototype. No backend, no payments, no real auth, no market data. Phase 0 builds only the visual foundation plus a live styleguide route you can review, then I stop for approval. ## Brand image Received: the sepia wolf head on black. It fits the palette almost exactly — warm greys against near-black read as a natural sibling to obsidian and warm gold, and the frontal stare carries the awareness/discipline symbolism without any hype. One honest caveat: the file is ~1080px square and visibly compressed, with soft edges and JPEG artefacting around the fur. It will look right at small-to-medium sizes and as a low-opacity atmospheric layer, but will show its limits as a full-bleed desktop hero. How I'll handle it: - **Phase 0**: register it as the brand mark asset (CDN pointer, no binary in the repo) and use it small — styleguide brand block, nav mark, favicon-scale contexts — where the resolution is invisible. - **Phase 1 hero**: use it as a large, low-opacity presence behind the headline with a vignette and gradient wash into obsidian, so softness reads as atmosphere rather than blur. If you want a crisp full-resolution hero instead, I can produce an upscaled cinematic treatment derived from this exact image so it stays your wolf, not a generic one — say the word and I'll do it in Phase 1. ## What Phase 0 delivers **Tokens** (in `src/styles.css`, all oklch, dark-first) - Raw values live as CSS custom properties on `:root` (`--bg-obsidian`, `--brand-crimson`, `--brand-gold`, …); `@theme inline` only maps them to Tailwind colour tokens. Nothing hardcoded inside `@theme`, so Phase 5 appearance work and contrast tuning happen in one place. - Obsidian `#0B0B0D` background, charcoal `#151518` surface, card grey `#202024`, border `#303035` - Text `#F2F2F2`, muted `#929297` - Crimson `#C9364F` (high-stakes and destructive), warm gold `#D4A84F` (progress, Marks, membership), forest green `#6FA879` (success) - Elevation shadows, focus ring, subtle grain/vignette utilities, radius scale **Typography** - Bebas Neue for headlines (condensed, cinematic), Barlow for body and UI - Root-route head: `preconnect`, then `rel="preload" as="font" type="font/woff2" crossorigin` for the Bebas Neue woff2 ahead of the stylesheet link, with `font-display: swap` - Size-adjusted local fallback metrics (`@font-face` with `size-adjust` / `ascent-override`) for both families so the swap causes no visible layout shift - Registered as `--font-display` / `--font-body`; display scale with tight tracking, body scale tuned for readability on dark **Components** (reusable, typed, mobile-first) - Buttons: **primary = stark off-white on obsidian** (high-intent, hyper-legible), secondary outline, ghost, gold (premium/reward), **crimson = high-stakes only**, destructive, sizes + loading/disabled states - Cards: base, elevated, bordered, gold-accented (achievement), interactive/hover - Forms: labelled input, textarea, select, checkbox, radio group, toggle, error message, helper text - Navigation: desktop top bar, member sidebar, mobile bottom nav, tabs, dropdown menu - Progress: linear bar (crimson/gold variants), progress circle, streak card, consistency meter - Content cards: course card, lesson card (locked/complete/in-progress), goal card, achievement badge (Mark) - Feedback: modal dialog, toast (sonner, mounted once in root), skeleton loading states, empty state, error state **Structure created now** - `src/types/` — starter interfaces (course, lesson, progress, member) - `src/data/`, `src/services/mockApi.ts` — scaffolding so pages never hold their own data - `src/components/ui/` for primitives, `src/components/` for brand components **Review surface** - `/styleguide` route showing every token, type scale, and component variant in one scrollable page. Kept during development, removed in Phase 7 unless you want it. - `/` stays a placeholder until Phase 1; I'll point it at the styleguide so the preview isn't blank. ## Locked rulings 1. **Secondary button = fully neutral.** Charcoal fill, `#303035` border, off-white text. No crimson edge. 2. **Progress colour map.** Active = gold, completed = forest green, missed check-in / broken streak = crimson. No crimson in standard progress fills. 3. **Typography enforcement.** `--font-display` (Bebas Neue) restricted to `h1`, `h2`, hero text, section headers, and large numeric stats — uppercase, short. `--font-body` (Barlow) for card titles, subheadings, nav, buttons, and all body copy. Enforced in the component layer, not left to discretion. 4. **Phase 5 "Dim" theme.** Second surface theme lifting obsidian toward slate charcoal, driven entirely by the `:root` variable layer. 5. Primary button = stark off-white on obsidian. Crimson reserved for high-stakes and destructive actions. 6. Demo auth: any credentials create a mock session in local storage; member routes redirect to `/login` without one, clearly labelled demo. 7. Imagery: driven by your brand image, used sparingly. ## Remaining suggestions 1. **Accessibility on crimson.** `#C9364F` on obsidian is below AA for small text. Fills, borders and large type only; small crimson text uses a lightened tint token so contrast stays compliant. 2. **Motion budget.** One shared transition (150–250ms ease-out) for hover/press, plus animated progress fills. Nothing else. 3. **Risk-disclaimer component.** A single reusable disclaimer block built now, reused in the Trading Room, pricing and landing so the honest-trading language never drifts. ## Two last challenges 1. **Off-white primary buttons compete with body text.** On obsidian, a solid `#F2F2F2` button is the brightest object on screen. If a card holds three of them, the page loses hierarchy fast. My rule: one off-white primary per view, everything else neutral or ghost. That constraint is worth committing to now — it shapes card layouts in every later phase. 2. **All-caps Bebas plus a strict word cap changes the copy, not just the type.** "Become 1% Better Every Day." is six words and lands perfectly; most dashboard section headers will not. Expect me to rewrite verbose section headings into 2–4 word forms ("The Den", "Today's Work", "Your Marks") rather than shrink the type. Flag it now if you want longer, sentence-case headings anywhere. ## Technical notes React 19 + TypeScript + Tailwind v4 on TanStack Start (file-based routing under `src/routes/`). Tokens live in `@theme inline` in `src/styles.css` — no `tailwind.config.js` on this stack. Components use semantic tokens only, never hardcoded colour classes. Dark is the only theme; the appearance setting in Phase 5 will be visual-only. ## Roadmap after approval Phase 1 public brand surface → Phase 2 core member experience → Phase 3 progress and accountability → Phase 4 community and sessions → Phase 5 profile and settings → Phase 6 admin → Phase 7 quality pass. I stop after each.
